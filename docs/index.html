Mvua Protocol documentation

Mvua is parametric climate insurance on Stellar. It pays smallholder farmers automatically when on chain weather data shows the season failed. No claim is filed, no adjuster visits, and no paperwork stands between a failed season and a payout.

This documentation explains the ideas behind the protocol, how a policy moves through its life, and how the contracts are built. If you are new here, read the concepts page first, then the protocol reference for the details.

What Mvua is

A smallholder with two hectares cannot be served by traditional crop insurance. The cost of assessing a loss exceeds the value of the premium, so no insurer offers the product. Mvua removes the assessment entirely: a payout is a function of a public, measurable index, so the cost of settling a claim approaches the cost of a transaction.

The protocol is built as five Soroban smart contracts on Stellar, in USDC. Capital sits in tranched risk pools, independent publishers deliver signed weather observations, and a payout vault settles automatically when a trigger fires.

Where the project is

The contract core is written, tested, and released. A live testnet season is in progress, which is the first time the protocol runs against real wall-clock time and real weather data. Mainnet is deliberately far off: it sits behind an external audit and a full beta season. The roadmap page has the honest state of each phase.

On provisional numbers

Some parameters in these docs, the premium curve, the timelocks, and the index thresholds among them, are marked provisional. They are placeholders chosen so the mechanism can be built and tested, and they will be calibrated from historical data before any real pool relies on them. Read them as the shape of the design, not as final commitments.
